# Статус открытой беты на 25.09.2026

Этот документ отделяет подтверждённые production-проверки от оставшейся
приёмки. Подробные требования — в [ТЗ](product-specification.md), команды для
нового образа — в [release checklist](release-checklist.md). Результат проверки
старого образа не подтверждает автоматически текущий deploy: точный образ и
состояние Git перед выпуском проверяются заново.

## Подтверждено владельцем проекта

- 18 сентября проверены одинаковый образ web и worker, готовность PostgreSQL и
  Redis, liveness/readiness, отсутствие рестартов и OOM.
- Резервная копия PostgreSQL и media успешно восстановлена в изолированном
  контейнере, скопирована за пределы production-хоста; контрольные суммы
  совпали. Перед последующей очисткой тестовых данных создана и проверена
  отдельная копия.
- Аудит 30 активных + 30 неактивных клиентов завершился `status: ok`,
  `errors: []`, кодом 0. После него web и worker оставались healthy без
  рестартов и OOM, readiness возвращала `ok`. Отдельно успешно проверены три
  ответа Семёна и публичный production smoke.
- Временная audit-комната, 60 аккаунтов и их сессии удалены; наличие комнаты,
  аккаунтов и файлов сессий повторно проверено. После очистки тестовых данных
  сохранены три согласованных аккаунта, пять публичных бесед и аватары;
  сообщения, заметки и 40 связанных файлов удалены. Возникший после запуска
  web/worker ответ 502 устранился после перезагрузки Nginx; readiness снова
  вернула `ok`.
- Открытая регистрация без приглашения и вход проверены владельцем; задача
  регистрации принята как выполненная. Для последующих образов подтверждены публичный smoke, готовность сервисов и
  отсутствие ошибок в проверенных журналах. GitHub/Google OAuth, Turnstile и
  добровольный Web Push проходили production-проверку ранее.
- Реализованы поиск сообщений и личных заметок, подгрузка старой истории,
  вложения, аудио, реакции, ответы, жалобы, закрытые беседы и восстановление
  входа после отказа WebSocket. Поиск заметок и последние улучшения composer
  опубликованы; проверка их работы на реальных устройствах продолжается.

## Остаётся подтвердить на текущем образе

1. Сверить SHA web/worker с опубликованным образом и выполнить адресный smoke
   затронутых сценариев по [чек-листу](release-checklist.md), включая журналы,
   restart/OOM и readiness. Уже пройденные длительные нагрузку и
   backup/restore не повторять без изменения соответствующего кода или
   конфигурации.
2. Провести отдельную проверку доступности форм и восстановления доступа с
   VoiceOver. Проверить composer и запись/воспроизведение аудио на iPhone и
   Android PWA. Принятую регистрацию повторно не открывать без нового дефекта.
3. Проверить значок уже установленной PWA на реальном устройстве; при
   необходимости переустановить PWA, поскольку обновление системной иконки
   может отставать от обновления страницы. Собрать замечания реальных
   пользователей по [сценарию приёмки](ui-beta-review.md).

## После беты или только по результатам измерений

- Apple OAuth, теги и возможное редактирование/экспорт заметок,
  расшифровка аудио, видеосообщения, предпросмотр внешних ссылок.
- Фоновый шум бара, согласованные русские версии цитат PEP и пакет промтов
  для оформления.
- Redis-кэш истории и публичных полей профиля — только при подтверждённом
  узком месте; PostgreSQL остаётся источником истины.

Новые функции и документационные PR в `develop` не означают автоматический
deploy в production. Перед новым выпуском сверяйте ветки, CI, опубликованный
образ и фактическое поведение на устройстве.
