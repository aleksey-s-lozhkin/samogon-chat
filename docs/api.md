# HTTP API

API предназначен для диагностики и будущих клиентов. Текущая версия доступна
под `/api/v1/`; несовместимые изменения получают новый префикс версии.

## Документация

- `/api/docs/` — интерактивный Swagger UI;
- `/api/schema/` — OpenAPI schema.

Схема публична и не содержит endpoint подписок, криптографических ключей,
секретов окружения или персональных данных. Защищённые операции используют
текущую Django-сессию. Для изменяющих запросов необходим CSRF cookie и заголовок
`X-CSRFToken`.

## Маршруты

### `GET /api/v1/chat/rooms/`

Возвращает только доступные текущему пользователю открытые и тайные комнаты,
включая число непрочитанных личных сообщений.

### `GET /api/v1/chat/rooms/{slug}/messages/`

Возвращает до 50 последних доступных реплик. Параметр `limit` принимает значения
от 1 до 100. Чужие личные сообщения и тайные комнаты не раскрываются.

### `POST /api/v1/chat/rooms/{slug}/messages/`

Создаёт обычную или личную реплику. Поля: `message`, необязательные `recipient`
и `reply_to`. Ответ на личную реплику автоматически сохраняет того же
собеседника. Сообщение сразу передаётся подключённым WebSocket-клиентам.

### `GET /api/v1/users/me/`

Возвращает безопасную публичную часть текущего профиля без email и прав доступа.

### `PATCH /api/v1/users/me/`

Изменяет выбранный статус пользователя. Принимает поле `presence_status`.

### `GET /api/v1/status/`

Возвращает версию API, состояние приложения, признак текущей авторизации и
доступность Web Push. Маршрут не требует входа.

### `GET /api/v1/push/subscriptions/`

Возвращает только устройства текущего пользователя. Вместо адреса push-службы
используется непрозрачный `device_id`. Требуется активная сессия.

### `POST /api/v1/push/self-test/`

Принимает `device_id` из предыдущего ответа и отправляет нейтральное тестовое
уведомление только на принадлежащее пользователю устройство. Запрос защищён
CSRF и ограничением частоты.

## Ошибки

Ошибки имеют короткий машинный код в поле `error`. Основные статусы: `400` для
неверного тела, `401` без сессии, `403` для недоступного аккаунта или CSRF,
`404` для чужого/неизвестного устройства, `429` при ограничении частоты и `503`
при отключённом Web Push. Внутренние исключения инфраструктуры клиенту не
передаются.

### Реакции и жалобы

- `POST /api/v1/chat/rooms/{room_slug}/messages/{message_id}/reactions/` —
  поставить или снять одну из разрешённых реакций. Ответ возвращает новый
  счётчик и отображаемые имена участников; изменение сразу отправляется
  подключённым WebSocket-клиентам.
- `POST /api/v1/chat/rooms/{room_slug}/messages/{message_id}/reports/` — создать
  жалобу с причиной и необязательным комментарием до 240 символов. Повторная
  жалоба того же пользователя не создаёт дубликат и не отправляет новый push
  модераторам.

Обе операции разрешены только для видимой пользователю неудалённой реплики.
Чужие личные сообщения и комнаты возвращают `404`, не подтверждая их
существование. На собственную реплику пожаловаться нельзя.

### Вложения

`POST /api/v1/chat/rooms/{room_slug}/messages/{message_id}/attachments/`
принимает `multipart/form-data` с одним или несколькими полями `files`. Добавлять
файлы может только автор видимой неудалённой реплики. Сервер проверяет весь
набор до сохранения: при ошибке одного файла не сохраняется ни один.

Разрешены проверяемые изображения JPEG, PNG и WebP, PDF, а также ограниченный
набор текстовых форматов. Действуют те же ограничения размера, количества и
частоты, что в Web-интерфейсе. Ответ содержит только безопасные метаданные и
защищённые URL просмотра/скачивания — внутренний путь хранилища не раскрывается.
После успешной загрузки открытые клиенты получают WebSocket-обновление.

## Ограничения первой версии

Заметки и вызов Семёна пока используют существующие Web/HTML или
WebSocket-маршруты. Они будут добавляться в API отдельно, без несовместимого
изменения текущих контрактов.

## Расширение API

Каждое приложение публикует собственный пакет `api/` и вызывает те же сервисы,
что Web и WebSocket. `config` подключает маршруты и собирает общую OpenAPI-схему;
предметная логика в `config` не переносится.
