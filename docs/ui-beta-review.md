# Визуальная приёмка беты

Согласованный владельцем вариант: фонарь с терминальным знаком. Альтернативы находятся в
`visual-identity.html`. Проверка реальными пользователями
ещё не выполнена; локальные проверки не заменяют эту приёмку.

Реализовано: единый знак на главной, в шапке и офлайн-экране; PNG для PWA и Apple,
отдельный монохромный badge; общие SVG бесед в карточках, меню и заголовке;
контрастные карточки, CTA «Войти в бар», более спокойные действия профиля,
переключатели уведомлений, свёрнутая диагностика, акцент реплик Семёна.
Открытая регистрация без приглашения проверена владельцем в production.

## Сценарий для реальных пользователей

Без подсказок: зарегистрироваться, выбрать беседу, отправить текст и аудио,
ответить на сообщение, найти профиль, включить уведомления и вернуться в чат.
Для каждого затруднения записать устройство, тему, шаг и ожидание пользователя.
Не сохранять пароли, cookies и содержание личных бесед в отчёте.

На iPhone и Android PWA проверить клавиатуру, возврат из фона, доступность
composer и обновление значка после переустановки PWA. У уже установленной PWA
обновление системной иконки может происходить отдельно от обновления страницы.

После нового deploy проверить затронутые сценарии, публичный production smoke
и журналы. Автоматическая проверка старого образа не подтверждает новый образ.
